¿Qué reglas se aplican?
  • Cédula: formato panameño (8-123-456, PE-12-345, E-8-12345).
  • Salario: número mayor que 0, sin símbolo de moneda.
  • Días laborados: entero entre 0 y 31.
  • Código de ocupación: dentro del catálogo.

Son reglas de ejemplo. Falta confirmarlas con la normativa de la CSS (HU-01).
